# 🍺 Homebrew Tap for caesar915-hub

Official Homebrew Tap for utilities and developer tools by [caesar915-hub](https://github.com/caesar915-hub).

---

## 📦 Available Casks & Formulae

### ⚡️ [Hermes Menu Bar](https://github.com/caesar915-hub/hermes-menubar)
Native macOS menu bar utility for [Hermes Agent](https://github.com/NousResearch/Hermes-Agent) and Telegram Gateways.

#### Installation

```bash
# 1-step installation
brew install caesar915-hub/tap/hermes-menubar
```

Or by tapping the repository first:

```bash
brew tap caesar915-hub/tap
brew install --cask hermes-menubar
```

#### Upgrading

```bash
brew upgrade hermes-menubar
```

#### Uninstalling

```bash
brew uninstall --cask hermes-menubar
```
